# AI Courses

Learn AI engineering by building it: interactive lessons, videos and labs for programmers, from your first model to a project you can show. Start free.

**[aicourses.dev](https://aicourses.dev)**

## Courses

### [AI Research Engineering](https://aicourses.dev/research)

From your first idea of what a model is to a GPT you trained, a fine-tune that wins and an RL run you can explain.

Free Colab notebooks for every module: **[ai-research-engineering](https://github.com/aicoursesdev/ai-research-engineering)**

### [Applied AI Engineering](https://aicourses.dev/applied)

From your first model call on your own laptop to an AI product that is measured, secured, deployed and monitored.

The code for every lesson, one repo you run on your laptop: **[applied-ai-engineering](https://github.com/aicoursesdev/applied-ai-engineering)**
